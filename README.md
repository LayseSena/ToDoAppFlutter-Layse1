## 📝 Projeto “Lista de Tarefas” (To-Do List)

Aplicação construída com **Flutter** (usando a linguagem **Dart**).  
O objetivo é permitir ao usuário **criar, visualizar, marcar como concluída e excluir tarefas**.  
Há também uma **busca** para filtrar tarefas por palavras-chave.  

O estado dos dados atualmente está em **memória (mock data)**, ou seja, sem backend ou banco de dados real conectado.  
É um projeto **simples e ideal para aprendizado de Flutter/Dart**.  

---

### ⚙️ Funcionalidades principais
- CRUD básico (Create, Read, Update/Conclude, Delete) de tarefas  
- Barra de busca para filtrar tarefas conforme digita  
- Avatar interativo (ao clicar, a imagem é ampliada via `AlertDialog`)  - To do
